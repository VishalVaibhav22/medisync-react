# MediSync – Doctor Appointment App (Frontend UI/UX Project)

MediSync is a modern, responsive **frontend web application** designed to provide a clean and intuitive interface for browsing doctors, viewing profiles, and scheduling appointments. Built with **React.js** and **Tailwind CSS**, the project focuses on UI/UX principles such as visual clarity, ease of navigation, and consistent styling.

This application serves as a **UI/UX prototype** and includes interfaces for patients, doctors, and administrators. All interactions, pages, and dashboards are implemented purely on the frontend for academic demonstration.

---

## 🎨 Design & UI Approach

The system uses a clean medical-themed layout with consistent spacing, colors, and typography. A component-based structure ensures reusability and visual uniformity across pages. Tailwind CSS enables responsive design, allowing the interface to adapt smoothly to mobile, tablet, and desktop screens.

---

## 🧑‍💻 Tech Stack

- **React.js** – Component-driven interface development  
- **Tailwind CSS** – Utility-first styling for responsive layouts  
- **React Router** – Smooth, reload-free navigation  
- **Context API** – State management within the frontend  
- **Visual Studio Code** – Primary development environment  
- **Git & GitHub** – Version control and project storage
